Decor Vendor Addon

Version: Work in Progress
Author: MidniteDestiny

About

Decor Vendor is a lightweight, user-friendly World of Warcraft addon designed to help you track, organize, and locate decoration vendors across all expansions. With collapsible expansion, continent, and zone headers, as well as profession-specific listings, you'll always know exactly where to go next for your housing needs.

Note: This addon is still a work in progress!

Features

Collapsible headers for expansions, continents, and zones.

Vendor listings with map coordinates for easy navigation.

Profession-specific vendor tracking.

Future updates will include a better filters system, better waypoint integration, and other quality-of-life features like pressing escape to close the addon or a hide minimap checkbox and brining back the hide visited vendor option.

Installation

Download the addon folder into your World of Warcraft/_retail_/Interface/AddOns/ directory. or install via GitHub or CurseForge

Launch WoW and ensure "Decor Vendor" is enabled in the AddOns menu.

Use the interface to explore vendors across all expansions.
