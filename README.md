Decor Vendor is a handy World of Warcraft addon that helps you track, organize, and locate in-game decoration vendors across all expansions. Stay ahead with filters, auto-hide functionality, and real-time vendor tracking to make your housing experience seamless!

## Features

- Track every vendor that sells housing decor, across all expansions
- Gallery Browser — browse every decor item by source, with 3D previews
- Filters by expansion, faction, source, and more
- Waypoints — right-click a vendor card or use the waypoint button to navigate
- Merchant checkmarks — see at a glance which items you've already collected
- Localization — ships in English, with volunteer translations on CurseForge
